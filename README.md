# Reels Maker

**Версия 1.1.2 · Windows**

Reels Maker — приложение для создания и оформления коротких видео для Reels, TikTok и YouTube Shorts. Помогает сократить время на монтаж и подготовить ролики к публикации.

**English:** Reels Maker is a Windows app for creating and styling short videos for Reels, TikTok, and YouTube Shorts. It simplifies editing and helps prepare videos for publication.

## Возможности

- **Умная нарезка** — подбор коротких фрагментов по речи, паузам и ключевым словам с настройкой длительности и количества клипов.
- **Субтитры** — локальное распознавание речи через Whisper или загрузка SRT, настройка шрифта, цвета и расположения текста.
- **Оформление видео** — фильтры, масштабирование, отражение, изменение скорости, логотипы и видеобаннеры.
- **Разделение экрана** — добавление дополнительного ролика («залипалки») с настройкой расположения и пропорций.
- **Работа со звуком** — регулировка громкости, отключение оригинальной дорожки, добавление музыки или озвучки.
- **Пакетная обработка** — обработка нескольких файлов и экспорт в форматы 9:16, 1:1 и 16:9 с настройкой разрешения, FPS и качества.

## Установка

После публикации установщика в разделе **Releases**:

1. Откройте **Releases** на странице репозитория.
2. Выберите нужную версию и скачайте EXE-установщик из списка **Assets**.
3. Запустите установщик и следуйте его инструкциям.
4. Откройте **Reels Maker**.

## Быстрый старт

1. Добавьте исходные видео в программу.
2. Настройте оформление, субтитры и звук.
3. При необходимости включите умную нарезку и задайте параметры клипов.
4. Выберите формат и качество экспорта.
5. Нажмите **«Обработать»** и выберите папку для результатов.

## Особенности работы

- Умная нарезка использует речь, паузы и ключевые слова для подбора фрагментов. Перед публикацией проверьте, что выбранные клипы закончены по смыслу.
- Распознавание речи выполняется локально. Для модели Whisper, которой ещё нет на компьютере, может потребоваться первоначальная загрузка через интернет.
- Скорость обработки зависит от длительности и разрешения видео, выбранных эффектов и мощности компьютера.
