# Сборка Reels Maker 1.1.2

## Что опубликовано

- `source/` — исходники доработок, сборщик и интеграционные тесты.
- `Reels-Maker.iss` — сценарий Inno Setup для упаковки подготовленного приложения.
- `LICENSE.txt` — сохранённая лицензия исходной программы.

Репозиторий не содержит полного исходного проекта. Сборщик заменяет и дополняет модули в исходном EXE; он не создаёт всё приложение только из опубликованных Python-файлов. Запуск одного `source/main.py` также требует отсутствующих здесь базовых модулей и библиотек.

## Пересборка приложения

Нужны Windows, Python 3.12 и оригинальный `ReelsMakerPro.exe` версии 1.0.0. Более поздняя изменённая сборка не является заменой оригиналу.

Поместите оригинальный файл в `source/original/ReelsMakerPro.exe`. Эта папка исключена из Git. Из корня репозитория выполните:

```powershell
py -3.12 source/build.py source/original/ReelsMakerPro.exe "dist/Reels Maker.exe"
```

Результат использует существующие библиотеки и ресурсы приложения; это не автономный EXE. Для запуска нужен совместимый комплект папок `_internal`, `transcriber` и остальных ресурсов из подготовленной сборки.

## Сборка установщика

Нужен Inno Setup 6.7 или новее и полностью подготовленная папка приложения. Она должна включать `Reels Maker.exe`, библиотеки, ресурсы, файлы лицензий, `INSTALL-NOTES.txt` и включаемые модели. Сценарий использует значок `_internal/resources/icon.ico`.

Передайте абсолютный путь к этой папке через `PayloadDir`:

```powershell
ISCC.exe /DPayloadDir="C:\path\to\application-folder" Reels-Maker.iss
```

Путь выше — пример: замените его на свой. Без параметра сценарий использует путь к рабочей папке первоначальной сборки, которой в этом репозитории нет.

Установщик появится рядом со сценарием. Для распространения прикрепите его к выпуску в разделе Releases.

## Проверки

Файлы `source/test_*.py` и `source/regression_tests.py` сохранены вместе с доработками. Это интеграционные проверки: им нужны исходная сборка, библиотеки и, для части сценариев, тестовые видео или аудио. Некоторые пути настроены под первоначальную рабочую среду; перед запуском изучите соответствующий файл и адаптируйте пути.

Этот архив подготовлен для публикации файлов. Повторная сборка приложения и запуск интеграционных проверок при упаковке архива не выполнялись.
